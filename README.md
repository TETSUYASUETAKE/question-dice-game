# 質問サイコロ

GitHub Pagesで公開できる、HTML/CSS/JavaScriptだけで作ったWebゲームです。
サイコロを振るようにボタンを押すと、質問リストの中からランダムで質問が表示されます。

## ファイルの役割

このゲームは、主に次のファイルで動きます。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の土台です。ボタン、質問を表示する場所、読み込むCSSやJavaScriptを指定します。 |
| `style.css` | 見た目を整えるファイルです。色、文字サイズ、余白、ボタンのデザインなどを変更できます。 |
| `script.js` | ゲームの動きを担当します。質問リスト、ランダム表示、ボタンを押したときの処理を書きます。 |
| `manifest.json` | iPhoneなどでホーム画面に追加したとき、アプリのように見せるための設定ファイルです。 |
| `README.md` | この説明書です。編集方法や公開手順をまとめています。 |

## 質問リストの編集方法

質問は、`script.js` の上の方にある `QUESTIONS` で管理します。

たとえば、次のような部分を探してください。

```js
const QUESTIONS = [
  {
    category: "自分を知る",
    text: "自分のすきなところを1つ言うなら？"
  },
  {
    category: "未来",
    text: "いつか行ってみたい場所はどこ？"
  }
];
```

質問を増やしたいときは、`QUESTIONS` の中に次のような形で追加します。

```js
{
  category: "友だち・家族",
  text: "だれかを笑顔にするなら、何をする？"
}
```

編集するときの注意点:

- `category` にはカテゴリ名を書きます。
- 使えるカテゴリは `自分を知る`、`友だち・家族`、`未来`、`今日の気持ち` です。
- `text` には表示したい質問を書きます。
- 文字は `"` で囲みます。
- 質問と質問の間には `,` を入れます。
- `[` と `]` を消さないようにします。
- 日本語、英語、絵文字なども基本的には使えます。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作ります。
2. このフォルダの中身をリポジトリにアップロードします。
3. GitHubのリポジトリ画面で、上部メニューの `Settings` を開きます。
4. 左側メニューの `Pages` を開きます。
5. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
6. `Branch` で公開したいブランチを選びます。初心者の場合は `main` を選ぶことが多いです。
7. フォルダは `/root` を選び、`Save` を押します。
8. 数十秒から数分待つと、GitHub PagesのURLが表示されます。

公開URLは、だいたい次のような形になります。

```text
https://ユーザー名.github.io/リポジトリ名/
```

うまく表示されないときは、次の点を確認してください。

- トップページのファイル名が `index.html` になっているか。
- `index.html`、`style.css`、`script.js` が同じフォルダにあるか。
- `index.html` から読み込むファイル名と、実際のファイル名が一致しているか。
- GitHub Pagesの設定で正しいブランチとフォルダを選んでいるか。

## iPhoneでホーム画面に追加する方法

GitHub Pagesで公開したゲームは、iPhoneのホーム画面に追加できます。
ホーム画面に置くと、アプリのようにすぐ開けます。

1. iPhoneでSafariを開きます。
2. GitHub Pagesの公開URLにアクセスします。
3. 画面下の共有ボタンを押します。
4. メニューの中から `ホーム画面に追加` を選びます。
5. 表示名を確認して、右上の `追加` を押します。

これで、iPhoneのホーム画面に「質問サイコロ」のアイコンが追加されます。

## 変更するときのおすすめ順

初心者の場合は、次の順番で編集すると安心です。

1. `script.js` の質問リストだけを変更する。
2. ブラウザで開いて、質問が表示されるか確認する。
3. 慣れてきたら `style.css` で色や文字サイズを変える。
4. 最後に `index.html` のタイトルや説明文を調整する。

まずは質問を1つだけ追加して、動くか確認してみるのがおすすめです。
