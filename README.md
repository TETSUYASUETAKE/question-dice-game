# 質問サイコロ

6面のサイコロに質問が書かれた、HTML/CSS/JavaScriptだけで動くWebゲームです。

遊ぶ人はカテゴリを選び、サイコロを振ります。1回のロールごとに、選択中のカテゴリから6問が選ばれてサイコロの6面に割り当てられます。ボタンをもう一度押すとサイコロが止まり、正面に出た面の質問に答えます。

GitHub Pagesで公開すれば、スマートフォンやPCのブラウザから遊べます。iPhoneなどではホーム画面に追加して、アプリのように開くこともできます。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の土台です。サイコロ、カテゴリ選択、ボタン、質問表示エリアなどを置いています。 |
| `style.css` | 見た目を整えるファイルです。3Dサイコロ、回転アニメーション、色、余白、スマートフォン表示などを調整します。 |
| `script.js` | ゲームの動きを担当します。質問リスト、カテゴリ選択、6面への質問割り当て、ロール処理、結果表示などを書いています。 |
| `manifest.json` | ホーム画面に追加したとき、アプリのように見せるための設定ファイルです。 |
| `README.md` | この説明書です。編集方法や公開手順をまとめています。 |

## 質問リストの編集方法

質問は `script.js` の上部にある質問リストで管理します。

初心者の方は、まず `script.js` を開いて、ファイルの上のほうにある `QUESTIONS` を探してください。そこにカテゴリと質問文がまとまっています。

例:

```js
const QUESTIONS = [
  {
    category: "自分を知る",
    text: "自分の好きなところを1つ言うなら？"
  },
  {
    category: "友だち・家族",
    text: "だれかに『ありがとう』と言うなら、だれに言う？"
  }
];
```

質問を増やすときは、`QUESTIONS` の中に次のような形で追加します。

```js
{
  category: "未来",
  text: "いつか行ってみたい場所はどこ？"
}
```

編集するときの注意:

- `category` にはカテゴリ名を書きます。
- 使えるカテゴリは `自分を知る`、`友だち・家族`、`未来`、`今日の気持ち` です。
- `text` にはサイコロ面に表示したい質問を書きます。
- 文字は `"` で囲みます。
- 質問と質問の間には `,` を入れます。
- `[`、`]`、`{`、`}` を消さないようにします。

## 6面への質問の割り当て

このゲームでは、サイコロを1回振るたびに質問が決まります。

1. 遊ぶ人がカテゴリを選びます。
2. そのカテゴリの質問リストから6問が選ばれます。
3. 選ばれた6問が、サイコロの6面に1問ずつ割り当てられます。
4. サイコロが3Dで回転し続けます。
5. もう一度ボタンを押すとサイコロが止まります。
6. 回転が止まったあと、正面に出た面の質問に答えます。

そのため、各カテゴリには6問以上入れておくのがおすすめです。6問より少ないカテゴリを作る場合は、同じ質問が出やすくなる可能性があります。

## 質問を編集するときのおすすめ手順

はじめて編集する場合は、次の順番で進めると安心です。

1. `script.js` の上部にある質問リストだけを編集します。
2. まずは1つのカテゴリに質問を1つ追加します。
3. ブラウザで `index.html` を開き、ゲームが動くか確認します。
4. 問題なく動いたら、ほかの質問やカテゴリも追加します。
5. 見た目を変えたいときだけ、あとから `style.css` を編集します。

## GitHub Pagesで公開する手順

GitHub Pagesを使うと、このゲームをWebページとして公開できます。

1. GitHubで新しいリポジトリを作ります。
2. このフォルダの中にある `index.html`、`style.css`、`script.js`、`manifest.json`、`README.md` をリポジトリにアップロードします。
3. GitHubのリポジトリ画面で `Settings` を開きます。
4. 左側のメニューから `Pages` を開きます。
5. `Build and deployment` の `Source` で `Deploy from a branch` を選びます。
6. `Branch` で公開したいブランチを選びます。通常は `main` を選びます。
7. フォルダは `/root` を選び、`Save` を押します。
8. 数分待つと、GitHub Pagesの公開URLが表示されます。

公開URLは、だいたい次の形になります。

```text
https://ユーザー名.github.io/リポジトリ名/
```

うまく表示されないときは、次の点を確認してください。

- トップページのファイル名が `index.html` になっているか。
- `index.html`、`style.css`、`script.js` が同じ場所にあるか。
- `index.html` から読み込んでいるファイル名と、実際のファイル名が一致しているか。
- GitHub Pagesで正しいブランチと `/root` を選んでいるか。

## ホーム画面に追加する手順

GitHub Pagesで公開したページは、スマートフォンのホーム画面に追加できます。ホーム画面に置くと、アプリのようにすぐ開けます。

### iPhoneの場合

1. iPhoneでSafariを開きます。
2. GitHub Pagesの公開URLにアクセスします。
3. 画面下の共有ボタンを押します。
4. メニューの中から `ホーム画面に追加` を選びます。
5. 表示名を確認して、右上の `追加` を押します。

これで、ホーム画面に質問サイコロのアイコンが追加されます。

### Androidの場合

1. AndroidでChromeを開きます。
2. GitHub Pagesの公開URLにアクセスします。
3. 画面右上のメニューを開きます。
4. `ホーム画面に追加` または `アプリをインストール` を選びます。
5. 表示名を確認して追加します。

## 変更するときの注意

- 質問を変えたいときは、まず `script.js` 上部の質問リストだけを編集します。
- カテゴリ名を変えた場合は、画面上のカテゴリボタンの名前や設定と合っているか確認します。
- 各カテゴリには6問以上あると、サイコロの6面に質問を割り当てやすくなります。
- 公開前に、PCとスマートフォンの両方で動作確認するのがおすすめです。
